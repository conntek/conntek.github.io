# 昆泰芯第一件欧洲专利：《磁性编码器的自校准方法、电机及校准角度检测值的方法》公告授权

## 专利授权概况

昆泰芯申请的发明专利《磁性编码器的自校准方法、电机及校准角度检测值的方法》已正式获得欧洲专利局的授权。这一成就标志着昆泰芯在磁性编码器技术领域的创新能力得到了国际认可。

<figure class="c-blog-fig"><img src="/msite/blog/first-european-patent/1.webp" alt="欧洲专利局 Rule 71(3) 通知书首页" loading="lazy"><figcaption>欧洲专利局 Rule 71(3) 通知书首页</figcaption></figure>

该专利涉及一种用于电机开环自校准的校准系统及方法，通过内置的自校准算法，能够修正由于磁铁安装和环境变化引入的误差，从而提高磁性编码器的精度和可靠性。这项技术不仅适用于电机控制领域，还广泛应用于伺服电机、激光雷达、光伏跟踪及手术机器人等高端工业场景。

## 意义与展望

该专利的授权进一步巩固了昆泰芯在磁性编码器领域的技术领先地位。通过自校准技术，昆泰芯的产品能够实现更高的精度和稳定性，满足更多高精度应用的需求。

昆泰芯的专利成功获得欧洲专利局授权，标志着其技术实力已跻身国际前沿行列，这将激励公司持续投入研发，推动技术创新。获得欧洲专利授权后，昆泰芯将能够在欧洲市场更加自信地推广其产品，提升品牌影响力和市场份额。这也将为昆泰芯走向全球化的战略布局提供强有力的支持。

<figure class="c-blog-fig"><img src="/msite/blog/first-european-patent/2.webp" alt="欧洲专利局通知书审查组签章页" loading="lazy"><figcaption>欧洲专利局通知书审查组签章页</figcaption></figure>

未来，昆泰芯将继续在磁性编码器、电机控制等领域深耕，力求推动更多创新技术的开发和应用，不断提升产品的性能和功能，继续引领行业发展。
