# 昆泰芯 KTM13 系列 TMR 磁开关芯片赋能洗碗机精准液位检测

液位检测是洗碗机实现节水控制、防溢保护的核心功能。传统方案常用霍尔开关或机械传感，在短行程、弱磁场、高湿高温工况下，易出现状态区分模糊、功耗偏高、可靠性不足等问题。昆泰芯 <a class="c-xref" href="/products/switch/ktm13">KTM13</a> 系列 TMR 磁开关传感器，以高灵敏度、超低功耗、宽温宽压优势，成为洗碗机液位检测的理想选择。

<figure class="c-blog-fig"><img src="/blog/ktm13-dishwasher-level/1.webp" alt="洗碗机应用场景" loading="lazy"><figcaption>洗碗机应用场景</figcaption></figure>

## 洗碗机液位检测核心需求

洗碗机采用浮子 + 磁铁结构，浮子随水位升降带动磁铁旋转，磁开关需精准识别 0° ~ 30° 角度区间磁场变化，清晰区分高低水位。传统霍尔开关灵敏度有限，短行程下磁场分界不明显，易误判；机械与光电方案易受水汽、油污干扰，寿命短。

## KTM13 系列核心优势

- 极致低功耗：50 Hz 版本仅 160 nA @ 3.0 V，远低于霍尔方案，助力家电节能降耗。
- 超高灵敏度：多档磁场阈值可选（±9 Gs ~ ±45 Gs），弱磁场下精准触发，短行程也能清晰区分水位状态。
- 全极检测易用：全极磁场感应，不区分 N/S 极，简化安装；CMOS 推挽输出，直连主控。
- 高可靠适配：工作电压 1.8 ~ 5.5 V，温度 -40 ~ 125 ℃，ESD 达 HBM 8 kV，适配洗碗机恶劣环境，符合 RoHS 标准。
- 小型化封装：SOT-23-3L、TO-92S 封装，贴装便捷，适配紧凑结构设计。

## 应用方案与价值

<a class="c-xref" href="/products/switch/ktm13">KTM13</a> 系列开关芯片通过非接触式检测浮子磁场变化，输出稳定电平信号，实现水位精准控制。针对短行程痛点，可微调磁铁与芯片位置，依托 TMR 高灵敏度解决霍尔难以区分的临界状态问题。

该方案带来四大价值：检测更精准，避免溢水与缺水；整机更节能，纳安级（nA）功耗满足低功耗设计；运行更可靠，无机械磨损，抗干扰强；量产更高效，简化结构，降低装配成本。

昆泰芯 <a class="c-xref" href="/products/switch/ktm13">KTM13</a> 系列 TMR 磁开关芯片，精准解决洗碗机液位检测传统方案痛点，以高性能、低功耗、高可靠特性，为智能家电提供稳定高效的液位感知方案，助力洗碗机产品升级，推动 TMR 技术在家电领域普及应用。
