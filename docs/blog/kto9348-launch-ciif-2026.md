# 昆泰芯 KTO9348 光编芯片将在 2026 中国国际工业博览会正式发布

<p class="c-post-meta"><span>2026-09-18</span><span>·</span><span>昆泰芯微电子</span><span>·</span><span>阅读约 8 分钟</span></p>

<p class="c-lead">KTO9348HI 是 KTO 系列的相位阵游标光编芯片：一次扫描 5 条码道，经三通道 Nonius 插值实现最高 25 bit 单圈绝对位置分辨率，将于 2026 中国国际工业博览会正式发布。</p>

<div class="c-takeaways"><b>本文要点</b><ul><li>相位阵列求和输出，放宽对准容差并保持信号保真度</li><li>M/N/S 三条模拟码道周期错开，游标差拍得到 25 bit 单圈绝对位置</li><li>与 <a class="c-xref" href="/products/encoder/ktm58">KTM5801</a> 信号调理芯片组合，构成完整信号链</li></ul></div>

<figure class="c-blog-fig c-blog-fig--hero"><img src="/blog/kto9348-launch-ciif-2026/2.webp" alt="昆泰芯 KTO9348 光编芯片将在 2026 中国国际工业博览会正式发布"></figure>

在高端伺服与绝对位置编码器领域，精度每往上走一步，难度都是成倍的。

当分辨率要求跨过 20 位，磁编芯片已经能交出不错的答卷；但当目标指向 25 位——单圈 3355 万分之一圈——光电编码器芯片凭借更高的信号保真度、以及对现场强磁场天然免疫的特性，依然是高端装备绕不开的选择。而长期以来，这一档性能的光电编码器芯片，几乎完全依赖进口。

昆泰芯（CONNTEK）KTO 系列产品——KTO9348HI 正式发布。

这是一颗 Phased Array Nonius（相位阵游标）光编芯片：单片集成高清相位阵列光电传感器，一次扫描 5 条码道，输出高保真的差分正弦/余弦信号，通过三通道 Nonius 插值实现高达 25 bit 的单圈绝对位置分辨率，并集成 2 位格雷码数字轨完成扇区检测。

## 高端伺服为何走向光编

### 分辨率的天花板

精密转台、机床主轴、测角设备对单圈分辨力的要求，正在向 20 bit 以上区间推进。25 bit 意味着把一圈分成 33,554,432 份——这个量级上，光电方案在信号保真度上的优势被充分放大，也是高端绝对式编码器长期选择光学路线的原因。

值得一提的是，这并不意味着「光」要取代「磁」。昆泰芯此前已用 <a class="c-xref" href="/products/encoder/ktm52">KTM52</a>/53 AMR（21 bit）、<a class="c-xref" href="/products/encoder/ktm59">KTM59</a> TMR（24 bit）覆盖了磁编码器芯片的高精度区间；KTO9348HI 的加入，让昆泰芯形成「磁 + 光」双技术路线——客户按精度要求、安装空间与现场环境，自由选型。

### 相位阵列化解对准难题

传统光电编码器芯片对装配对准极为敏感：码盘与芯片之间稍有一点偏心或倾斜，信号质量就会明显下滑，产线不得不为微米级的装配精度「过度较劲」。

KTO9348HI 采用相位阵列（Phased Array）光电传感器——在每条码道上排布多个光电探测单元，阵列求和输出。带来的直接好处是：对对准偏差的容忍度显著放宽，同时保持优秀的信号保真度。对编码器厂商而言，这意味着装配难度、标定工时与量产一致性风险同步下降。

### 强磁场与高温环境

伺服电机、大电流母线、电焊工位附近，磁场环境复杂。磁编码器芯片的软肋正在于此，而光电方案天然不受外部磁场干扰。同时 KTO9348HI 采用超低暗电流设计，配合 -40 ~ 125 ℃ 的工作温度范围，高温工况下信号依然稳得住。

## 五码道扫描原理

KTO9348HI 单片集成 3 通道相位阵列，可同时扫描 5 条轨道：

- 3 条模拟轨（M/N/S）：每条码道配置多个光电传感器，生成差分正弦（SIN±）与差分余弦（COS±）共 6 路信号。差分信号路径采用配对放大器结构，确保各通道之间的信号匹配性与共模行为一致；
- 2 条数字轨（MTA/MTB）：输出 2 位格雷码，完成嵌入式扇区检测，用来区分重复的 Nonius 刻度，把「相对位置」变成「绝对位置」。

三条模拟码道的周期数被刻意错开——M 码道 2×1024 CPR、N 码道 2×1023 CPR、S 码道 2×992 CPR——利用 Nonius（游标）差拍原理，把三种不同刻线的相位信息组合成一把「绝对标尺」，从而实现 25 bit 单圈绝对分辨。

<figure class="c-blog-fig"><img src="/blog/kto9348-launch-ciif-2026/2.webp" alt="KTO9348HI 感光区域与五轨扫描结构示意" loading="lazy"><figcaption>KTO9348HI 感光区域与五轨扫描结构示意</figcaption></figure>

配套码盘的规格同样清晰：适配直径 33 mm（33.2 mm）的光栅码盘，2048 刻线游标；光半径 14.5 mm，码盘有效半径区间 13.06 ~ 15.94 mm；每主信号周期内允许的最大轨间信号相位偏差仅 ±4.9°（电角度）——这个「宽松」的数字，正是相位阵列带来的装配红利。

## 六大核心优势

### 25 bit 单圈绝对位置

把一圈分成 3355 万份。

2²⁵ = 33,554,432。上电即知转子在 360° 内的绝对角度，无需寻找零位、无需回零动作。对伺服系统而言，这意味着开机即可锁定位置、断电不丢单圈位置，省去了增量式方案「上电必须回零」的节拍损耗与安全隐患。

说明：25 bit 指芯片的单圈绝对分辨能力（分辨率）；系统最终角度精度还取决于码盘刻线质量与机械安装精度，实际指标以客户整机测定为准。

### 相位阵列光电传感

把「对准」这件难事变简单。

每条码道上排布多个光电探测单元，阵列化求和输出：对准容差宽松，信号保真度高。产线不必为微米级光学对准反复调试，量产一致性更有保障——这是 KTO9348HI 最核心的差异化能力之一。

### 高增益 + 低噪声

微弱光信号也能「看得清」。

- 允许光电流范围 0 ~ 1120 nA，典型跨阻增益 0.95 MΩ（规格区间 0.7 / 1 / 1.4 MΩ）；
- 得益于 0.95 MΩ 的互阻增益，即使在低光照条件下，输出信号电平也能达到几百毫伏；
- -3 dB 截止频率 400 kHz，RMS 输出噪声仅 0.5 mV，光敏度 0.3 V/μW；
- 暗电平与参考电压 VREF 典型值均为 770 mV。

高增益 + 低噪声的组合，意味着 LED 驱动电流可以更低、码盘刻线可以更细、系统信噪比留有余量。

### 差分输出 + 低输出阻抗

长线传输不怕干扰。

差分信号路径采用配对放大器结构，天然具备优秀的共模抑制能力；内部输出电阻典型仅 110 Ω（70 ~ 180 Ω），低输出阻抗进一步增强 EMI 抗扰度；输出端还内置短路保护（高 / 低负载短路电流均被限制在安全区间）。编码器内部走线、穿过电机附近的噪声环境时，信号完整性更有保障。

### 超低暗电流 + 宽温高可靠

高温工况稳得住。

- 超低暗电流，高温下暗电流不抬升，工作温度 -40 ~ 125 ℃；
- 光谱应用范围 400 ~ 950 nm，峰值灵敏度波长 680 nm，推荐红光光源；光源电流最低 0.3 mA 即可保证数字输出引脚 MTA / MTB 的准确性；
- 上电稳定时间 ≤ 100 μs，MT 信号上电稳定仅 8 μs，推荐光照时间 3 μs；
- ESD 耐压 HBM ±2 kV / CDM ±2 kV，闩锁测试 ±800 mA；
- MSL3 潮敏等级，支持 245 ℃ 回流焊，符合 RoHS 标准。

### 芯片之外的完整方案

拿到的不只是芯片，还有可直接上手的验证条件。

- 32-pin optoQFN 封装，本体尺寸仅 5.00 mm × 5.00 mm、高度约 0.90 mm，引脚间距 0.50 mm，便于小型化设计；
- 支持评估板与码盘采样；
- 典型应用电路中，KTO9348HI 与 <a class="c-xref" href="/products/encoder/ktm58">KTM5801</a> 信号调理芯片（双 16 bit SAR ADC、CORDIC 与校准引擎、SPI 输出）组合，构成从光信号采集到角度解算的完整信号链，可直接对接 MCU 或伺服驱动器。

数据手册给出的两大典型应用是——绝对位置编码器与交流伺服反馈。围绕这两条主线，该芯片的能力还可以延伸到更广的高精度位置感知场景（属技术推演，具体以客户系统设计评估为准）：

- 交流伺服电机反馈
- 绝对式旋转编码器
- 机床主轴/数控转台
- 机器人关节与精密减速器
- 精密测量与科研仪器
- 光电转台/稳定平台
