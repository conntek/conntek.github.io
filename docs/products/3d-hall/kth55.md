# 高精度 3D 霍尔磁性角度传感器—— 55系列

<p class="ct-subtitle">高精度垂直霍尔绝对角度传感器 - KTH5502</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/KTH55XX.png" alt="高精度 3D 霍尔磁性角度传感器—— 55系列"></div><div class="ct-hero-body">

KTH5502 是一款基于垂直霍尔技术的高精度绝对角度传感器芯片，支持全角度（0–360°）测量。芯片内部集成 X、Y 轴的垂直霍尔元件和 Z 轴的水平霍尔元件，能够同时感知磁场在 X、Y、Z 三个方向的变化。得益于垂直霍尔技术先进的工艺匹配特性、低失调设计和高性能信号链，KTH5502 内部通过高精度放大电路和 16 位 ADC 将磁场信号转换为数字信号，并结合专用的算法处理，实现 XY 平面内的高分辨率绝对角度输出。

## 产品特点

- 高精度垂直霍尔技术，支持全角度（0–360°）测量
- 16-bit 分辨率绝对角度输出
- 宽工作电压：1.7V ~ 3.6V
- 宽温度范围：-40℃ ~ +125℃
- 低功耗：典型工作电流 4–6mA
- 丰富接口：I²C、SPI、AB 正交编码、PWM、模拟电压
- 最高支持转速 5000RPM
- AB 正交编码输出最高 1024 线/圈
- 支持 SOP-8L 和 DFN2×2-8L 封装
- 符合 AEC-Q100 车规标准
