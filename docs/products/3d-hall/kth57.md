# 3D磁角度传感器芯片—57系列

<p class="ct-subtitle">3D线性/角度传感器芯片</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/magneticAngleEncoderChip.jpg" alt="3D磁角度传感器芯片—57系列"></div><div class="ct-hero-body">

昆泰芯KTH5701是一款数字输出型三轴线性霍尔传感器芯片，可以测量XYZ三个方向的磁场分量。该传感器可作为I2C和SPI从机与外部主控进行数据交互，支持不同的工作模式和配置，从而让用户在磁场测量性能和芯片功耗上取得最佳平衡。集成温度传感器配合内部温度补偿算法可有效减小磁场测量的灵敏度温漂。
用户可以根据实际应用场景，开启一轴或多轴组合的磁场测量，获取磁场原始数据后结合软件算法，可以提取待测物体（磁铁）的运动信息，适用于摇杆、旋钮、位移测量等应用场景。该传感器面向工业和消费类应用，可为用户提供卓越的使用体验。

## 主要优势

- 小型QFN封装3X3mm
- 灵活的工作模式和参数在线配置，实现性能和功耗的最佳平衡
- I2C与SPI通信方式可选
