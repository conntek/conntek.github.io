# 编码器芯片

<p class="c-lead">霍尔、AMR、TMR 与光学路线的高速高精度编码器芯片</p>

<div class="c-stats"><div class="c-stat"><b>7</b><span>产品系列</span></div><div class="c-stat"><b>25</b><span>份技术文档</span></div><div class="c-stat"><b>2</b><span>个产品视频</span></div></div>

编码器芯片解决的是「转到哪了」——把电机轴或旋转机构的绝对角位置变成数字量，供伺服环路闭环。衡量它的三个量是分辨率（一圈分成多少份）、精度 INL（读数与真实角度的偏差）与最高转速，三者往往不能同时拉满，选型就是在这三者与安装条件之间取舍。

本类目覆盖三种感磁路线加一条光学路线：霍尔的 KTH78、KTH71 胜在低延时与在轴离轴通吃；AMR 的 KTM52、KTM53 工作在饱和区（饱和磁场约 300 高斯），主要响应磁场方向而非强度，因而对磁铁加工误差与安装距离误差容忍度较高；TMR 的 KTM59 与细分器 KTM58 做到 180,000 rpm 与 30 bit；KTO95 是光学前端，输出正弦 / 余弦供后级插值。

## 常见问题

::: details KTM58 和 KTM59 差在哪

KTM59 自带 TMR 感磁，直接输出 24 bit 绝对角度；KTM58 不感磁，需外接 AMR/TMR 或光编、光栅、磁栅的正余弦信号。

:::

::: details 自校准要做什么操作

KTM52、KTM53 为用户侧一键自校准，补偿磁铁不理想与安装偏差引入的非线性误差；KTH71 内置 ANLC，写寄存器或引脚触发，结果存入片内 MTP。

:::

::: details 能替代增量光电编码器吗

KTM52、KTM53 的增量 ABZ 最高 65,536 脉冲/圈、UVW 1 ~ 64 对极；KTH78 为 ABZ 4 ~ 4096 步/圈。

:::

::: details KTO95 输出的是角度吗

不是。KTO95 输出 6 对模拟差分正弦 / 余弦信号，由后续设备插值，具体型号经三通道 Nonius 插值可达 24 位单圈分辨率。

:::
