# 16 位高速高精度磁编码器 - KTH71系列

<p class="ct-subtitle">16 位高速高精度磁编码器 —— KTH71系列</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/1760937016155.png" alt="16 位高速高精度磁编码器 - KTH71系列"></div><div class="ct-hero-body">

KTH7101 是一款高速高精度的磁编码器，内置了先进的自动非线性校准（ANLC）功能。
用户可通过写入寄存器或引脚触发校准流程，芯片能够自动完成传感器非线性误差的测
量与补偿参数计算，并将校准结果存入内部 MTP（多次可编程存储器）。此功能无需复
杂外部干预，可显著提升角度测量的线性度， 实现优于 ±0.1° 的绝对精度。

## 产品特点

- 16 位高精度绝对角度输出
- 在轴应用，校准后 INL 精度 &lt; ±0.1°
- 离轴应用，校准后 INL 精度 &lt; ±0.2°
- 支持单对极和多对极磁铁应用
- 超低延时：1μs 数据更新率
- SPI 通信：至高 10Mbps 数据交互
- 工作电压：3.3V 至 5V
- 工作温度：-40°C 至 125°C
- 工作温度范围：-40℃~125℃
- 封装：SOP-8 4.9mmx6mm
- 符合 AEC-Q100 车规标准
