# 高速高分辨率磁编码角度传感器 - KTH78系列

<p class="ct-subtitle">高速高分辨率磁编码角度传感器</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/msite/images/hshrMagneticCodedAngleSensor.jpg" alt="高速高分辨率磁编码角度传感器 - KTH78系列"></div><div class="ct-hero-body">

昆泰芯KTH78xx系列是一种16位分辨率高精度低延时霍尔绝对角度编码器，可以测量XY两个方向的平面磁场分量。该传感器支持四线制SPI绝对角度输出（CRC输出校验可选），两线制SSI绝对角度输出，可编程4-4096步/圈ABZ增量输出，可编程1-8对极UVW增量输出，PWM占空比角度输出。芯片集成报警功能，用户可根据需求编辑磁场过低、过高的报警阈值。

KTH78xx系列全系支持在轴或离轴应用，我司可为客户提供磁仿真服务，帮助客户在各种应用场景获得更好的精度。该系列芯片INL误差低至±0.35°，噪声低至0.007°，系统延时为1us且系统内部做了延时补偿，温度范围最高支持-40至125℃，适用于汽车角度控制、绝对角度位置传感器、无刷直流电机、步进闭环、电梯、 屏蔽门、AGV搬运机器人等多种场合。

## 主要优势

- 超低延时，每 1μs 更新一次数据
- 支持离轴应用
- 支持多对极磁铁
- 符合 AEC-Q100 标准
- CRC校验输出可选
- 磁场强度诊断/报警
- 3.3V/5V供电可选
- 超小QFN16_3x3mm封装和SOP8封装可选
