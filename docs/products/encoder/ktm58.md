# 30bit 绝对角度细分器 - KTM58 系列

<p class="ct-subtitle">30bit 绝对角度细分器——KTM5800 系列</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/1760693879963.png" alt="30bit 绝对角度细分器 - KTM58 系列"></div><div class="ct-hero-body">

KTM5800 是一款 30bit 绝对角度细分 4096 对极编码细分器，可以与磁电阻传感器（AMR/TMR）搭配，构成一个高速高精度的非接触磁性编码器模块。它具有以非常高的采样速率读取传感器上的差分模拟正弦和余弦信号的能力，可以通过其高速数字电路进行角度计算， 并输出位置信息。此外，KTM5800 还可以搭配其他传感器如光编/光栅/磁栅等，一圈或一个绝对机械周期允许最大 12bit（4096 线）多极对输入。

## 产品特点

- 单对极细分角度最高可达 18bit
- 最大支持 4096 对极输入
- 内部集成超高性能双 16bit 2M SAR ADC
- 最大支持 36M SPI 角度输出及寄存器读写
- 1-65536 线可编程 ABZ 增量输出
- 1-256 对极可编程 UVW 增量输出
- 独立 PWM 绝对角度输出
- 集成自动线性校准与自动非线性校准
- 单对极校准后 INL≤±0.025°
- 集成可编程增益运放
- 超高带宽输入，80M 内部主频，超低延时
- 适配光编/光栅/磁编/磁栅各种信号输入细分
- 工作温度范围-40°C 至 125°C
- 封装为 QFN32-5\*5mm
