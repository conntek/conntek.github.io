# 高速高分辨率TMR磁编码器芯片- KTM59系列

<p class="ct-subtitle">高速高分辨率TMR磁编码器</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/ext/hshrTMPA.png" alt="高速高分辨率TMR磁编码器芯片- KTM59系列"></div><div class="ct-hero-body">

昆泰芯KTH5900是一款 24bit 绝对角度 TMR 磁性编码器，构成一个高速高精度的非接触磁性编码器模块。它具有最高 2M 采样速率的 16bit SAR ADC 读取传感器上的差分模拟正弦和余弦信号的能力，可以通过其高速数字电路进行角度计算，并输出位置信息。

</div></div>

## 主要优势

- 超高带宽输入，80M 内部主频，超低延时
- 单对极细分角度最高可达 24bit
- 最大支持 36M SPI 角度输出及寄存器读写
- 独立 PWM 绝对角度输出
- 内部集成超高性能双 16bit 2M SAR ADC
