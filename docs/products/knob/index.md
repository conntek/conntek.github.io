# 旋钮系列

<p class="c-lead">磁-电分离的磁旋钮，隔空检测角度，防水防尘 IP67</p>

<div class="c-stats"><div class="c-stat"><b>1</b><span>产品系列</span></div><div class="c-stat"><b>0</b><span>份技术文档</span></div><div class="c-stat"><b>0</b><span>个产品视频</span></div></div>

磁旋钮是成品模块而不是裸芯片。它采用磁-电分离设计，旋钮以隔空方式把角度传给检测电路，面板不需要开孔让转轴穿过，密封面因此保持完整——这是它与传统机械编码旋钮最实际的区别。

防护能力包括防水 IP67、防尘 IP67、防油 IP67F、防静电 8 kV、防高温 125 ℃ 与防震动（Fdb）。模块化设计使形态可厚可薄、可大可小，安装可磁吸、可隐藏、可折叠，即插即用；极简结构带来的是开模成本小、上市快、组装效率高。

## 常见问题

::: details 隔空角度检测是什么意思

旋钮采用磁-电分离设计，旋钮本体与检测电路之间以隔空方式传递角度，面板无需开孔穿轴。

:::

::: details 能用在潮湿油污环境吗

磁旋钮具备防水 IP67、防尘 IP67、防油 IP67F 能力，另有防静电 8 kV、防高温 125 ℃ 与防震动（Fdb）。

:::

::: details 形态与安装方式有哪些

产品形态千钮千态，可厚可薄、可大可小；模块化设计使安装可磁吸、可隐藏、可折叠，即插即用。

:::
