# 零温漂高精度运放芯片—KTAX33系列

<p class="ct-subtitle">KTAx333</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/msite/images/zeroDriftAmplifierChip.png" alt="零温漂高精度运放芯片—KTAX33系列"></div><div class="ct-hero-body">

KTAx333是一款低失调，微功耗，可以实现轨到轨输入/输出的CMOS运算放大器。其使用自校准技术以提供极低的失调电压（2μV，典型值），KTAx333系列提供出色的CMRR性能，而不存在与传统互补输入级关联的交叉。该设计可在驱动模数转换器（ADC）的过程中实现优异的性能，而不会降低微分线性。这些特性使KTAx333非常适合用于各类传感器的信号的放大级。
