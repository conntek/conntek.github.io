# 1D霍尔开关-微功耗系列产品

<p class="ct-subtitle">霍尔微功耗系列产品</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/microPowerSeries.png" alt="1D霍尔开关-微功耗系列产品"></div><div class="ct-hero-body">
