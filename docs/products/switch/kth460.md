# 微功耗超灵敏的 3D 霍尔开关 - KTH460系列

<p class="ct-subtitle">微功耗超灵敏的 3D 霍尔开关</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/1760325627829.png" alt="微功耗超灵敏的 3D 霍尔开关 - KTH460系列"></div><div class="ct-hero-body">

KTH4603系列是一款具有X、Y、Z三维全极检测的低功耗霍尔效应开关传感器。该芯片可以提供多种开关工作频率和封装形式以适配各种应用。
芯片内置X,Y,Z三个超灵敏低失调的霍尔盘、多路模拟开关、差分放大器、施密特触发器和NMOS开漏输出电路，采用了先进SPIN及数字滤波技术、
优化时钟控制技术从而保证芯片稳定的工作点和开关频率。

## 产品特点

- 低功耗：2.5Hz版本：4.5uA@2.5V<br>5.0Hz版本：7.1uA@2.5V
- 宽工作电压范围：2.5V~5.5V
- 磁场阈值（Bop）25Gs 阈值
- 全极磁场检测
- NMOS开漏输出
- 封装：SOT-23-3L，SOT-23-6L
- 工作温度范围：-40℃~125℃
- 工作温度范围：-40℃~125℃
- 符合RoHS标准
