# 线性霍尔芯片（旧版页面）

<p class="ct-subtitle">线性霍尔芯片</p>

<div class="ct-hero"><div class="ct-hero-img"><img src="/images/linearHallChip.jpg" alt="线性霍尔芯片（旧版页面）"></div><div class="ct-hero-body">

线性霍尔效应传感器可按比例响应磁通量密度。内部电路包含霍尔传感器、线性放大器和CMOS输出级电路。具有高速、低噪声输出特性，在-40℃至125℃的宽温度范围内实现线性性能。可用于消费类工业类各种磁场检测。 具有宽工作电压范围，当不存在磁场时，模拟输出 1/2VCC。输出会随施加的磁通量密度呈线性变化，四个灵敏度选项可根据所需的检测范围提供最大的输出电压摆幅。
