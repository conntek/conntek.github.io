# 磁仿真&技术服务

<p class="c-lead">以电路设计、磁路设计、结构设计三项能力为核心，服务覆盖从可行性分析到量产磁路良率优化的项目全周期。</p>

## 核心能力

<p class="c-sec-lead">懂结构、懂设计、懂磁路、懂电路。</p>

昆泰芯可提供磁仿真服务，核心能力为电路设计、磁路设计与结构设计。

服务贯穿项目全周期：前期做可行性分析与最优传感器选型，设计阶段做与结构正相关的磁路设计，量产阶段做磁路良率优化。

## 解决思路

<p class="c-sec-lead">通过磁学仿真、磁路设计，并与电路、结构低成本快速迭代，最终实现功能。</p>

<div class="c-flow"><span><em>1</em>磁路设计</span><span><em>2</em>电路设计</span><span><em>3</em>结构设计</span><span><em>4</em>低成本快速迭代</span></div>

## 服务内容

<p class="c-sec-lead">覆盖从立项评估到量产良率的四个环节。</p>

<div class="c-grid c-grid--2"><div class="c-step"><span class="c-step__no">01</span><h3>可行性分析</h3><ul><li>想要实现什么功能？</li><li>方案是否存在先天性缺陷？</li><li>如何克服缺陷并实现想要的功能？</li></ul></div><div class="c-step"><span class="c-step__no">02</span><h3>最优传感器选型</h3><ul><li>是使用南极磁场触发产品、北极磁场触发产品还是南北极磁场均可触发的产品？</li><li>传感器所处位置适合什么类型封装？</li></ul></div><div class="c-step"><span class="c-step__no">03</span><h3>与结构正相关的磁路设计</h3><ul><li>磁路结构设计是否合理？</li><li>磁场强度是否满足传感器需求？是否存在左右耳机磁场相互干扰？吸附磁铁是否影响传感器工作？</li></ul></div><div class="c-step"><span class="c-step__no">04</span><h3>量产磁路良率优化</h3><ul><li>磁路不良品问题分析，定位问题位置，是磁铁工差较大还是组装工差较大，指导整改方向。</li></ul></div></div>
